# По правилам — подготовка к ЕГЭ по русскому языку

Сайт: **https://dolepp.github.io/Rules/**

208 заданий из демоверсий ФИПИ 2020–2027 годов с официальными ключами: проверка ответа, выбор года, переходы между примерами, случайное задание и повтор ошибок. Восемь тем сочинений проверяются самостоятельно по критериям ФИПИ; для них есть сохраняемый черновик и примерный подсчёт слов. Все 27 тем имеют не менее 5 примеров. Повторяющиеся задания объединены; исходный год, номер и страницы указаны у каждого примера.

27 страниц по заданиям: конспекты, алгоритмы, примеры, вопросы для самопроверки и документы ФИПИ. Поиск работает по названиям и текстам правил. Можно сохранять избранное, отмечать изученное и вести заметки. Личные данные хранятся только в localStorage браузера.

## Источники и актуальность

Основной источник — [навигатор подготовки ФИПИ](https://fipi.ru/navigator-podgotovki/navigator-ege): восемь тематических документов 2026 года и тренировочный список. Каждая страница задания содержит ссылки на соответствующие оригиналы на `doc.fipi.ru`.

Нумерация 1–27 и баллы сверены с [проектом демоверсии и спецификации ЕГЭ-2027](https://fipi.ru/ege/demoversii-specifikacii-kodifikatory). Дата проверки: **1 ноября 2026 года**. На эту дату ФИПИ обозначает комплект 2027 года как проект. После публикации окончательного комплекта необходимо проверить требования повторно. Не следует представлять конспекты как полный или дословный текст официальных документов: это самостоятельные учебные объяснения по темам ФИПИ, а примеры и вопросы составлены для сайта.

Все **63 файла (25 531 317 байт)** из [предоставленной папки Mail](https://cloud.mail.ru/public/J7ng/uXLQeE4Q2) сохранены без изменения содержимого в `assets/materials/`. Их названия, исходные ссылки, размеры и SHA-256 записаны в `data/materials.json`. Изображения и PDF открываются в просмотрщике, текст DOCX дополнительно доступен в `data/documents/` (без исходного форматирования). Один DOCX в исходной подборке не содержит текста; оригинал также сохранён. Материалы 2023–2025 годов обозначены как дополнительные: их требования и номера не должны заменять текущие документы ФИПИ. Права на исходные материалы принадлежат их авторам.

## Запуск

Без сборки и зависимостей:

```sh
python3 -m http.server 8000
```

Открыть `http://localhost:8000`. Для загрузки JSON нужен HTTP-сервер, открытие `index.html` через `file://` не подходит.

## Изменение материалов

- `data/practice.json` — официальные задания: условия, ответы, годы, исходные номера, страницы ключей и ссылки на архивы ФИПИ.
- `assets/practice/` — фрагменты оригинальных страниц ФИПИ. Для каждого условия доступно также чтение текста.
- `quiz-core.js` — сравнение ответов с учётом порядка цифр и допустимых вариантов.
- `data/lessons.json` — 27 заданий: правила, шаги, примеры, вопросы, ссылки на источники.
- `data/sources.json` — официальные источники ФИПИ.
- `data/materials.json` — каталог исходных файлов из облака, распределение по заданиям.
- `index.html`, `styles.css`, `app.js` — интерфейс без фреймворка и внешних CDN.

При обновлении экзамена проверь нумерацию, баллы, формулировки, требования к сочинению и дату актуальности на главной странице, в разделе источников и в этом README.

## Проверка и публикация

```sh
node --check app.js
node scripts/check.mjs
node scripts/quiz.test.cjs
```

Проверяются состав заданий, официальные домены источников, все локальные файлы, размеры и контрольные суммы исходников. GitHub Actions запускает проверки при каждом push в `main`, затем публикует сайт через GitHub Pages. Для репозитория должен быть выбран источник Pages **GitHub Actions**. Сборка приложения не требуется; подготовка артефакта для публикации выполняется в Actions.

Сайт адаптирован для телефонов, поддерживает клавиатурную навигацию, печать правил, прямые ссылки вида `#/task/12` и `#/task/12/fipi`. Для поиска: `Ctrl+K` / `⌘K` или `/`.

Архивные задания распределены по современной теме, но их формулировки, число соответствий и требования к сочинениям могут отличаться от действующих. В тренажёре оценивается совпадение с официальным ключом, а не рассчитываются экзаменационные баллы. Ответы и условия авторских учебных примеров из первоначальной версии сайта не используются вместо ключей ФИПИ.
